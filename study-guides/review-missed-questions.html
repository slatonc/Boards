How to review missed ABIM-style questions

For The Boards · Published September 4, 2026

A useful review note tells you what to do differently next time. It does not need to reproduce the entire explanation.

It is easy to spend an evening reading rationales and finish with pages of notes you will never reopen. Try making each note answer three questions: What was I being asked to decide? What changed that decision? What will I ask myself when I return to this topic?

1. Identify the task before the diagnosis

Write down whether the question asked you to identify a condition, interpret a result, select a test, choose treatment, or decide what happens next. Recognizing a diagnosis is not the same as answering the requested management question.

If you selected a reasonable action at the wrong point in a sequence, label the mistake that way. “I did not know this disease” is a less useful note when the real gap was the order of decisions.

2. Describe why your answer was tempting

Before studying the rationale, finish this sentence: “I chose my answer because…” Keep it specific. Perhaps you anchored on the first symptom, overlooked a time course, treated an incidental finding as decisive, or changed an answer without new evidence.

Then compare your reasoning with the source explanation. Check whether the explanation resolves your uncertainty. If it does not, use an appropriate current reference or ask a teacher. Do not turn an unclear rationale into a confident rule.

3. Save one decision and one contrast

Your note can usually be shorter than the question. Capture the feature that matters and the alternative you confused it with. Include a source or question identifier so you can find the complete explanation later.

Reusable note format

Presentation or topic: …
Task being asked: …
Clue that changes the answer: …
Why my alternative does not fit: …
Question to ask myself later: …
Source and date checked: …

For a sequencing mistake, an abstract example might be: “I recognized the condition but answered the later treatment question. On review, first ask what information or action the vignette requires now.” Add the actual clinical rule only after checking the source and its context.

4. Turn the lesson into a question

A highlighted statement is easy to recognize when you read it. A prompt asks you to produce the answer. Try “Which detail separates these two possibilities?” or “What would make the next step change?” rather than copying a paragraph under a disease heading.

Keep the answer out of view when you test yourself. If you cannot explain it, return to the original source and revise the note. A short note that you understand is more useful than a compressed note that has lost an important exception.

5. Put the note where you will look for it

Choose one main home for review notes. A printed companion can work well when the margin sits beside the relevant presentation. If you use a separate notebook, keep a simple topic index or reference the page in your review book.

Avoid maintaining the same lesson in several places. When a later question changes your understanding, update the existing note. You should be able to find the current version without remembering which app, page, or file you used first.

6. Revisit it on another day

Choose a return date when you write the note. You might try it the next day and again the following week, then adjust based on whether you can explain the decision. Those intervals are a practical starting point, not a fixed prescription.

When you revisit a question you remember, explain the reasoning before selecting an answer. Remembering which letter was correct does not tell you whether you can solve a similar question with a different presentation.

Keep the review queue small enough to use

  • Save repeated mistakes and important decisions before isolated details.
  • Include confidently wrong answers, not just questions that felt difficult.
  • Retire or shorten notes you can explain reliably.
  • Keep uncertain or changing recommendations linked to a current source.

Fit this cycle into your weekly study plan. To try annotating beside a presentation, open a free sample page and add one question-bank lesson of your own.
